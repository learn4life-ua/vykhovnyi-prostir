Запит для підготовки навчально-виховного заходу

Укажіть тему та, за наявності, зміст і власні матеріали заходу. Для запланованого заходу без готового змісту помічник запропонує свої варіанти. Помічник складе запит для методичної розробки, якою зможуть скористатися колеги. Скопіюйте його в обраний текстовий ШІ (рекомендовано ChatGPT). Усе працює у вашому браузері, дані нікуди не надсилаються цією сторінкою.

Стан заходу

Достатньо одного джерела: опишіть зміст або прикріпіть файл сценарію чи презентації в розмові з помічником (ChatGPT). Дублювати зміст файла у формі не потрібно.

Запит для методичної розробки

Скопіюйте запит. Якщо маєте файл, прикріпіть його окремо вже в обраному ШІ (рекомендовано ChatGPT). Ця сторінка не зчитує файли.

Перед використанням перевірте факти, авторство, персональні дані та відповідність реальному перебігу заходу.
