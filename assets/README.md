# Спільні ресурси сайту

- `images/` — спільні зображення та логотипи, коли вони з’являться.
- `css/` — спільні стилі, якщо сайт потребуватиме окремих файлів стилів.
- `js/` — спільні скрипти, якщо вони будуть потрібні.

Ресурси окремого заходу зберігаємо в його папці в `materials/`. Не розділяємо автономний HTML-помічник на зовнішні залежності.
