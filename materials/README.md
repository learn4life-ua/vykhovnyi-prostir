# Матеріали заходів

Кожен захід має власну папку всередині папки року, наприклад `2026/2026-11-05-den-dobroty/` (приклад назви, не реальний захід).

Сценарій, презентацію, зображення та роздаткові матеріали зберігайте разом. Додайте README з темою, автором, аудиторією та переліком файлів. Детальні правила — у `../docs/README.md`.
