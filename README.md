# Виховний простір коледжу

Сайт з матеріалами та інструментами для виховної роботи.

## Структура

- `index.html` — головна сторінка сайту.
- `tools/` — інтерактивні помічники. Кожен інструмент має власну папку.
- `tools/event-helper/index.html` — помічник для підготовки виховного заходу. Цей самий файл можна завантажити й відкрити без інтернету.
- `materials/` — авторські матеріали заходів: сценарії, презентації, роздаткові матеріали.
- `assets/` — спільні зображення, стилі та інші ресурси сайту.
- `docs/` — інструкції з ведення сайту.

Правила додавання файлів: [docs/README.md](docs/README.md).

## Запуск

На комп’ютері відкрийте `index.html`. Для окремого використання помічника відкрийте `tools/event-helper/index.html`. Встановлення програм, сервер і ключі API не потрібні.

Для публікації на GitHub Pages використовуйте гілку `main`, папку `/ (root)`. Після ввімкнення Pages очікувана адреса: https://learn4life-ua.github.io/vykhovnyi-prostir/ . Наявність файлів у репозиторії сама по собі ще не вмикає сайт.

## Про помічник

Він формує текст запиту, а не генерує готову розробку через API. Дані не зберігаються після оновлення сторінки. Файли та запит потрібно передавати в обраний ШІ самостійно.

Перевірено логіку формування запитів, режими запланованого та проведеного заходу, копіювання з резервним способом і повідомленням при відмові та завантаження українського тексту у UTF-8. Перевірка в реальному браузері ще потрібна.
